Padeladd Isolated API & App-Only Architecture Implementation Plan Ultra Secure

Complete Isolation: Isolated Web API, No Live Web Registration/Verification, Dedicated Password Reset, and OTA Protection.

🎯 Architecture Overview & Strategy

Padeladd live web presence will be completely stripped of interactive player features (no registration, no verification, no login, no dashboard). Live web pages will communicate exclusively with dedicated, isolated endpoints inside /app/api/, keeping the core /backend/api/ 100% dedicated to mobile native apps.

💻 1. Local Workspace (MAMP)

Retains full frontend/ codebase. Developers can test and debug all web app features (dashboard, ranking, matches, scoring, chat) locally on http://localhost:8888/padeladd4.

🚀 2. Live Server (`padeladd.com`)

Hosts only /app (Landing page with store links & Password Reset form calling /app/api/reset_password.php). frontend/ is NEVER uploaded.

📋 Directory & Component Matrix

Directory / Component Live Web Server State API Endpoint Used Purpose & Functionality
/frontend DO NOT UPLOAD (Omitted) None Local web development only. Completely absent from live server.
/app/index.html (Landing) UPLOADED None (Static) App Store & Google Play Store download links + app feature highlights.
/app/reset-password.html UPLOADED /app/api/reset_password.php Standalone Password Reset form for users opening email reset links on web.
/app/terms.html, privacy.html, rules.html UPLOADED None (Static) Legal & Privacy Policy web documents.
/share (Match Preview) UPLOADED /backend/api/match/details.php Shared match preview card (match.php) + OpenGraph tags for social sharing.
/backend/api UPLOADED (Mobile Only) Mobile REST API Dedicated 100% to iOS and Android native app traffic.
/downloads/bundles UPLOADED OTA Sync Capacitor Updater Over-The-Air (OTA) zip bundles for native apps.

📁 Minimal Structure of Live `/app` Folder

  • /app/index.html: Landing Page with Store download links.
  • /app/reset-password.html: Password reset form receiving token from email link.
  • /app/api/reset_password.php: Dedicated, isolated PHP script handling password reset logic directly.
  • /app/terms.html, privacy.html, rules.html: Legal compliance pages.
🔒 Maximum Security Guarantee: Live web visitors are strictly isolated inside /app/ calling only /app/api/reset_password.php. Core mobile API /backend/api/ is completely decoupled from web browser traffic.
